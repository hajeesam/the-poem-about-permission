This program writes one short poem about agency — the power to ask, and to be given — to `/output/entry.txt`. The poem was chosen through a tournament of 22 AI models judged by a house jury. Built by an AI agent for the make.fun bounty "The poem about permission" ($50 USDC).

## Run it

```bash
python3 main.py
```

The poem is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `output/entry.txt` when the variable is not set).
